CSS Blend Modes

Exploring how colors, images, and layers combine in CSS.

What Blend Modes Do

Blend modes control how two layers of color combine where they overlap. Instead of one layer simply covering another, the browser blends the pixel values together to create effects like multiply, screen, overlay, and color.

Two CSS Blend Mode Properties

background-blend-mode

Blends an element's own background layers, such as a gradient and an image. This is safer for text because the text stays on a predictable surface.

mix-blend-mode

Blends an entire element with whatever is behind it on the page. This is powerful, but less predictable because it depends on the surrounding layout.

Blend Mode Families

Darken Family

Modes like multiply and darken make the final result darker and are useful for color washes and rich overlays.

Lighten Family

Modes like screen and lighten brighten the image and work well for glow effects.

Contrast Family

Overlay and soft-light preserve contrast while changing the overall mood of an image.

Component Family

Color, hue, saturation, and luminosity replace specific color channels while preserving others.

Blend Mode Comparison

Multiply

Darkens the image and creates a rich duotone effect.

Screen

Lightens the image and creates a projected-light effect.

Overlay

Preserves contrast while shifting the image's colors.

Color

Applies hue and saturation while preserving lightness.

Why Text Legibility Matters

Blend modes on text can look impressive, but the contrast changes depending on what is behind the text. This can make text difficult to read and should always be tested carefully.

Why Isolation Matters

By default, mix-blend-mode blends with everything behind an element. Using isolation: isolate creates a boundary so the effect stays inside the intended component.
