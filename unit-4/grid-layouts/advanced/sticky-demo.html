Advanced Layout Notes

Sticky positioning is useful when an element should scroll normally at first, then lock into place once it reaches a specific offset.

The important part is that the sticky element needs an offset, such as top. Without that offset, the browser has no point where the element should begin sticking.

This demo uses a sidebar as the sticky module. As the article scrolls, the sidebar remains visible so the reader can quickly see the main ideas from the page.

Why Sticky Can Break

A common problem happens when an ancestor wrapper has overflow: hidden. That ancestor can become the sticky element’s scroll container, which prevents the sticky behavior from working the way you expect.

In this assignment, the bug was tested by adding overflow: hidden to the layout wrapper. The fix was to avoid placing overflow on the ancestor between the sticky element and the page scroll container.
